# 合约整局得分能力对比

日期：2026-10-26。状态：分析与建议，未改游戏参数或用户已确认档位。

## 结论

- 优先提货每箱20分暂不建议提高。它按每次落箱时仍无遮挡的对应货主箱数重复奖励，三份真实清单的合法布局回放中，整局自身贡献为4460至5560，已高于长期客户新设计在默认24只对应货主下的3240。
- 复核有强组合潜力，但当前没有充分依据认定其必然高于加急，不建议仅凭“能复制”就启用第四级。建议暂归蓝档；这是待用户确认建议，复核等级仍待定，紫档仍预留。
- 已确认分档是当前设计决定，不等于已证明蓝档在所有构筑下都高于绿档。长短接力理想交替的整局理论上限11280，尤其需要正视，不能因容易中断就按新标准直接折价。不能同时宣称“只看极限收益”与“现有档位已经严格按上限排好”。

## 优先提货20分：真实清单的合法布局回放

读取当前生成器，使用三个固定种子。每批按原车道顺序处理；长箱按颜色分入前四个箱位，短箱按颜色分入后两个箱位的指定半侧。当前颜色／尺寸配比保证这一布局能合法装完每列24箱、36半箱位，两列基础＋同色共4800。

每次通过现有拾取、放置及落位合法性检查，再调用当前无遮挡统计函数，累计两家货主各自的有效箱数。第一列归档布局在第二列统计中保留。

边界：这是三个合法摆放序列的分数回放，不是真人胜率、全局最优解、全种子统计或真实商店获取模拟。为分析完整两列，未执行阶段分数门槛和选卡时间限制，未启用货主支持，也没优化周转车或为优先提货专门改布局。两家版本是分别评价同一布局下的贡献，不表示一次必须同时持有两张。回放不改变游戏状态或参数。

判断：20只是一个“箱次”的奖励，并非一只箱子一生只加20。现有重复计分已能产生数千分，目前不建议仅因单次数字小就上调。若未来局长缩短、早切列或获取时点较晚，贡献会变化，需要另看实战。

## 复核是否应该进入第四级

用最直接的倍率组合说明。假设每次落箱执行合约前恰有100分，其他合约为空，重复48次：

| 持有组合 | 每次结果 | 整局结果 |
|---|---:|---:|
| 无上述两张 | 100 | 4800 |
| 只有加急 | 150 | 7200 |
| 只有复核，无可复制左邻 | 100 | 4800 |
| 加急→复核 | 225 | 10800 |

这是整除算例，不是默认真实清单的基础分结构。按已确认的相同其他合约条件下含／不含目标合约的分差：

- 固定加急，加入复核：10800－7200＝3600。
- 固定复核，加入加急：10800－4800＝6000。

因此“能再乘一次1.5”并不证明复核一定高于加急。它在本例中反而更依赖搭配；这种依赖不自动扣分，但也不自动升档。其他复制对象可能产生不同的相对贡献，不能将本例当作所有组合的上界。

复核真正的潜力是可随当前强左邻切换，能兼顾大额封顶、成长加分和倍率；这种灵活性可能有价值，但当前分级主要看最终得分能力，不应单凭灵活性额外升到紫档。后续若在实际合法组合中发现它相对其他蓝档有明显更高的可达最终贡献，再讨论第四级更有依据。

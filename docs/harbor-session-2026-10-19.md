# 港口吊装：2026-10-19讨论归档

历史快照提示：双车补位、必须全装完、无限撤销、固定专色工单和满列奖励等已被后续讨论替代。当前以[10月21至22日归档](harbor-session-2026-10-22.md)和[未来规划](harbor-future-plan.md)为准，下文保留当时记录。
本轮记录：未来规划、用户取舍、原型验证与未决问题。最新综合入口见[未来规划](harbor-future-plan.md)。

## 一、最新拍板

| 主题 | 决定 |
|---|---|
| 核心流程 | 操作员把卡车上的箱子装到船上；点击自动移动，到位手动确认抓放，升降自动。 |
| 货单与获胜 | 每关数量固定，必须全部装完后结算；**取消提前离港**，提前达分仍继续装船。 |
| 高分方向 | 分数不按目标封顶；固定货量下通过摆放、工单与后续倍率提高收益。不是追加无限货物，也不能重复搬运刷分。 |
| 第一关 | 四色、两尺寸、空船开局、固定专色装船教学工单；暂不加冷藏供电。 |
| 双车 | 同时两车，任选其一；未取车保留，取空车按固定货单自动补位。 |
| 反馈 | 得分进度条；每次落箱弹出箱子得分、工单得分，装满奖励单列。 |

**2600目标、24箱与3200自然最高分均是当前原型配置，不是完整版永久参数。** 现有简单工单没有实现无限成长；更大的得分空间仍需倍率与成长体系。

## 二、原型现在是什么样

| 项目 | 当前实现 |
|---|---|
| 船舱 | 单列6位，每位左右两个半位、最多3层，合计36半格；箱位近乎贴合。 |
| 货物 | 24箱：每色3长箱＋3短箱，红蓝黄绿四色；40尺占两半格，20尺占一半格。 |
| 支撑 | 长箱需两侧等高且有空位；短箱可选左右半位，自动微调对准。这是实验规则，完整版支撑细节仍待定。 |
| 计分 | 每半格50；上下同色箱子奖励25，专色工单再加25；装满一次奖励200。 |
| 结算 | 全部24箱完成且达到2600才通过；未达分可撤销调整或重试。分数达标不会自动结束。 |
| 操作节奏 | 移动、升降与车辆进出为原先1.5倍速度；撤销不限次数。 |
| 场景 | 横向船体，船头／船尾在画面左右方向；驾驶舱固定俯视，船舱开局为空。 |
| 船岸 | 道路与船舷紧邻；三车道只略宽于车辆，两辆车整体靠船。 |
| 尺寸表现 | 箱体保留集装箱比例；车上箱子约为船舱中部同尺寸箱子的97%显示长度，长短拖车分别适配。 |
| 导航与灯 | 右侧为船舶区／卸货区；吊具空载绿灯、载货黄闪，轻振可关闭。 |

## 三、工单：目标已明确，深度仍不足

用户期望工单像小丑牌：持续影响得分或集装箱属性，并能形成搭配。用户反馈目前工单太简陋、玩法仍枯燥，这个问题**尚未解决**。

可继续研究的六个方向，均不代表已批准实施：

| 方向 | 候选作用 |
|---|---|
| 货物专精 | 指定颜色、尺寸或特殊货物获得收益。 |
| 摆放组合 | 同色成塔、多色混装、逐层齐平等不同摆法。 |
| 属性判定 | 两种颜色按同色计分等；不轻易抹掉冷藏、危险品的真实约束。 |
| 结算触发 | 完成某种组合时再次计分、额外触发。 |
| 持续成长 | 随装载行为积累加分或倍率，形成越来越强的打法。 |
| 代价换收益 | 接受某项限制，获得较高奖励。 |

原型曾试三选一：专色装船、联合运输、整齐交付。现在第一关只用专色装船；其余保留作候选。工单叠加、属性转换、成长、倍率、跨阶段选择、资源商店尚未实现，也未全部定案。

设计表达可以用“规则卡＋最小场景示例＋可调实验台”。独立工单实验台曾提出，尚未制作；不能把当前驾驶舱原型当作已经完成的实验台。

## 四、车流移动：已讨论，尚未采用

用户提出让下方车流持续移动，以增加抓取时机和现场感。

- 背景车流只能增加热闹感，不能单独解决决策无聊。
- 候选交互：两车道缓慢来车，提前看颜色与尺寸；点击选车自动对准，进入宽松抓取区后手动确认，短暂停车完成抓取。
- 第一关候选补救：错过的车绕行再来，不罚分、不丢货；这些细节尚未最终确认。
- 避免车速太慢增加等待、太快挤掉摆放思考。流动车流应单独试验，当前仍是双车停车取货。

## 五、留到后续／尚待决定

| 项目 | 状态 |
|---|---|
| 冷藏箱、供电箱位 | 已认可方向，用户明确后续关卡再加。 |
| 目的港、卸货先后、危险品隔离 | 保留完整版方向，具体规则和解锁顺序未定。 |
| 多列船舱、预装地形 | 完整版保留，当前未实现。 |
| 有限周转位、重搬、限制撤销 | 候选；第一关目前仍不限撤销。 |
| 重量、双箱吊装、检查固定工序 | 尚未决定。 |
| 快速作业模式 | 曾建议用于区分等待与决策问题，未实施。 |
| 常规构筑＋每日固定高难挑战 | 总方向延续，跨关系统和每日机制尚未实现。 |

已放弃或被替代：提前离港；第一关工单三选一；三色作为当前第一关配置。此前放弃的独立装载区域加成继续不采用。

## 六、验证与限制

- 自动检查覆盖大小箱支撑、双车独立补位、预览与实际增分、撤销、容量、完整货单判定及超额分数。
- 浏览器实测：第20箱2600分仍显示剩余4箱；第24箱按3200分结算，保留超出目标的600分。
- 模拟1000次随意合法操作：114次装满、886次空间堵塞；装满样本中位2200分。这不是人类通关率，也不能证明已经好玩。
- 真实手机振动、长时间疲劳、难度曲线与传播／收入仍待验证。

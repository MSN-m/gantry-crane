## Cozy Cargo — 重点参考，用户认可

- 记录日期：2026-10-20。
- 游戏：[Cozy Cargo](https://vanova.itch.io/cozy-cargo)。
- **用户原话：“这个可以”“手感不错”。** 这是用户的体验反馈，作为后续设计的重要参考依据。
- **参考优先级：重点、优先研究。** 后续讨论装箱手感、摆放反馈、标签联动与得分构筑时，优先回看此游戏。
- 后续观察：选取与摆放的操作节奏、落位声画反馈、联动收益的可读性，以及单次摆放与整关构筑之间的联系。上述是待分析方向，尚不能把用户对整体手感的认可归因到某个具体机制。
- 用户认可此参考不等于批准照搬全部规则；具体借鉴内容仍逐项讨论。

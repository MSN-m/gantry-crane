# 港口一班 · 工单、大小箱与双车原型

竖屏手机，固定驾驶舱俯视、横向船体。6个紧密箱位，各含左右两个半位，最多3层，共36半格。20尺短箱占1半格，40尺长箱占2半格；本班各12箱，总计24箱。红蓝黄绿四色，每色3长箱＋3短箱，货单固定。箱体长宽高采用150:30:32与74.5:30:32近似比例。

## 开局与操作

运行 node server.cjs，打开 http://localhost:4173/ 。第一关固定使用「专色装船」同色教学工单。A/B车同时在场，任选一车抓取，另一车原货保留。取空车驶离后，队首自动补入该位置；补位中不能抓取。后续仅作预告，不可自由重排。

点击实物或车辆按钮、底部位置栏自动移动，到位手动确认抓放；移动与升降保持1.5倍速度。短箱可点击船位左右半边，或使用左／右半位按钮；驾驶舱自动横向微调到半位，镜头仍固定在驾驶舱，吊具与驾驶舱共同对准。长箱需要两半位等高、有连续空间，不允许悬空跨放。此支撑规则是本轮实验规则。

右侧船舶区到03，卸货区回到有货的车辆。底部栏可横向查看。键盘0=A车，7=B车，1–6=船位，空格=确认。作业期间禁重复触发，移动中可改选或停止。撤销恢复两车、货单、箱堆、工单进度与分数。

## 场景与反馈

横向靠泊的船体、密集箱位、码头双车道和车辆补位。吊具空载绿灯、载货黄闪，轻振可关闭。真实手机振动尚未验证。

## 验证

运行 node check.cjs：三个工单各完成24箱／36格，验证独立补位、长期保留另一车、大小箱支撑、三层容量、短箱半位、精确预览、深层撤销、完成奖励与工单里程碑不刷分。

浏览器：先取B车、保留A车；短箱右半位落箱；长箱拒绝不等高箱位；联合运输触发300工单分；320px窄屏无横向溢出，主按钮55px、半位按钮90×48px。

## 得分进度与弹分反馈

顶部进度条的第一关过关线为2600分。固定24箱必须全部装完，提前达分只作提示；装满但未达标会显示失败与差额，可撤销最后一步调整或重试。每次落箱弹出箱子得分（基础＋同色）和工单得分；无工单加分显示未触发，装满奖励单列。弹分约2.8秒自动消失，重开与撤销清理反馈，进度同步回退。最后一次弹分完成后再显示结算。分数不按2600封顶，不增加额外货物。支持减少动态效果设置。

## 第一关：四色与真实分数门槛

过关线2600，固定同色工单，不加入冷藏、供电或流动车流。装满基础1800＋完成200＝2000，必须通过同色组合补足至少600分（同色箱子分与工单分合计）。现有简单工单的自然最高分为3200，未设置人为得分上限；同色规划在第20箱、32格时达到2600，仍须装完剩余4箱才结算。更高的得分空间需要后续倍率或成长工单。撤销不限次数，第一关不额外增加操作惩罚。

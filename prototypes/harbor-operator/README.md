# 港口一班 · 同色堆叠积分原型

手机竖屏驾驶舱固定俯视。卡车依次送来红、蓝、黄、红、蓝、黄六箱，船上三个位置各可叠两层。背景箱堆仅作装饰，尚未加入大小箱与初始地形。

## 启动与操作

运行 `node server.cjs` 并打开 http://localhost:4173 ，或直接打开 index.html。开局已经对准卡车，可以直接确认抓取。

点击画面货物、船位或底部位置按钮自动移动，到位后确认抓取/落箱；下降、锁定或释放、提升自动完成。移动中可改选、停止。底部按钮显示当前容量，持货时显示每个可落位的预计增分。满两层的位置拒绝继续堆放。

## 积分

- 已放到船上的箱子每箱 100 分，吊着的货物不计分。
- 每一摞上下同色额外 50 分，混色可以正常完成。
- 六箱全部放稳后额外 200 分，只计一次。
- 完美同色配对：600 + 150 + 200 = 950 分。
- 全部混色：600 + 0 + 200 = 800 分。
- 分数由当前布局计算。撤销恢复箱堆、队列、载货和积分；重新放回不会重复刷分。
- 不计速度、不扣失误分，不加入限时连击。

## 反馈与验证

吊具横梁上空载绿灯、载货黄灯闪烁，轻振可关闭。真实手机振动效果未验证。

`node check.cjs` 覆盖同色950/混色800、每次预览与实际增分一致、完成奖励、撤销重做、嵌套箱堆历史、容量、提前确认与点击区域。浏览器完成六箱950分并验证撤销回600分。桌面数字键选择位置，空格确认。
